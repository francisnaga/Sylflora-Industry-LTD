## Overview

Sylflora Industry LTD is a modern corporate web platform engineered to represent industrial manufacturing, commercial product distributions, and institutional contracts. Built for high performance, accessibility, and visual authority, the site provides procurement teams and enterprise clients with an intuitive portal to review product specifications, manufacturing capabilities, and order pipelines.

---

## Key Features

- **Industrial Product Catalog**: Categorized specifications, technical datasheets, and material grades with filtering and search.
- **Enterprise RFP & Inquiry Pipeline**: Validated request-for-proposal forms routing client requests directly to procurement teams.
- **Quality & Certification Display**: Interactive audit exhibits highlighting compliance certifications, safety ratings, and manufacturing standards.
- **Responsive Architecture**: Fully responsive layouts optimized for corporate desktop procurement and mobile site visits.
- **Accessible UI Components**: Built on Radix UI primitives ensuring WCAG compliance, screen reader support, and full keyboard navigation.

## Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/francisnaga/Sylflora-Industry-LTD.git
   cd Sylflora-Industry-LTD
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run development server**:
   ```bash
   npm run dev
   ```

4. **Production Build**:
   ```bash
   npm run build
   ```
